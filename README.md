## キボマンシーとは

キボマンシーは、3個の六面サイコロと円を使って楽しむ、カジュアルなサイコロ占いです。

サイコロの出目の合計と、円の内側・外側に出たサイコロの数を組み合わせて、問いに対する神託を読み解きます。

古代から伝わるサイコロや距骨を用いた占い、伝統的な数値占いの発想を参考に、現代向けに再構築した独自の方式です。

難しい道具や専門知識は必要ありません。日々のちょっとした判断や、運試し、遊びのひとときに気軽に楽しんでください。

## AIによるリーディング

キボマンシーは、人がサイコロを振り、その結果をAIが読み解く楽しみ方にも対応しています。

マニュアル自体をAIに読み込ませれば、AIに結果を解釈してもらえます。

解釈の表現や語り口にはAIごとの個性が現れます。それもキボマンシーの楽しみのひとつです。
